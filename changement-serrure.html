UNE INTERVENTION
ADAPTÉE À VOTRE PORTE

01

Le cylindre ou la serrure entière ?

Le cylindre est la partie dans laquelle vous introduisez la clé. Son remplacement peut rendre les anciennes clés inutilisables sans changer tout le mécanisme. Nous vérifions si cette solution convient à votre installation. Si la serrure est détériorée ou inadaptée, nous vous expliquons les possibilités de réparation ou de remplacement.

02

Différents types de mécanismes

Nous intervenons sur les serrures monopoints et multipoints, notamment les modèles à trois points, ainsi que les serrures en applique, carénées ou encastrées. Les dimensions, le sens d’ouverture et les fixations orientent le choix du matériel. Une référence précise ou une photo de votre équipement facilite la préparation de votre demande.

03

Votre besoin de sécurité

Après une perte de clés ou une tentative d’effraction, nous examinons les éléments concernés avant de proposer une solution. Si votre contrat d’assurance demande un équipement certifié A2P, signalez-le : nous pouvons proposer un modèle correspondant. La certification concerne le produit choisi et ne constitue pas une garantie générale contre toute intrusion.

04

Un prix expliqué avant les travaux

Nous annonçons le prix avant l’intervention. Le type de serrure, les pièces nécessaires et les conditions du dépannage influencent le montant. Pour une demande programmée, contactez-nous avec la marque, le modèle si vous le connaissez et une description du problème. Nous vous indiquons comment transmettre les informations utiles à l’étude de votre remplacement.
